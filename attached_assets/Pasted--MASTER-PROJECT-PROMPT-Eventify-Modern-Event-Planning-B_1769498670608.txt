 🚀 MASTER PROJECT PROMPT
Eventify – Modern Event Planning & Booking Platform
📌 Project Overview

Build a full-stack, real-world event planning and booking platform called Eventify.
The platform allows users to discover event types, select multiple events, customize them, and book professionally managed events, similar to how real event companies work.

This project must be portfolio-ready, scalable, cleanly architected, and production-oriented.

🎯 Core Vision (VERY IMPORTANT)

Eventify is not just a listing app.

It is:

A decision-based event selection system

With persistent selections

A guided booking flow

And a clear separation between exploration, selection, and confirmation

This mimics real user behavior in event planning.
